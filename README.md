# Job Portal Website

A feature-rich job portal where job seekers can browse and apply for jobs, while employers can post job openings and manage applications. This platform aims to bridge the gap between job seekers and recruiters by providing an intuitive and efficient solution.

## Features

### For Job Seekers
- **User Authentication**: Register, log in, and manage accounts securely.
- **Profile Creation**: Create and update profiles, upload resumes, and showcase skills.
- **Job Search**:
  - Filter jobs by category, location, company, and job type.
  - Save jobs to favorites for later reference.
- **Job Applications**:
  - Apply directly to job postings.
  - Track application status.

### For Employers
- **Company Profiles**: Create and manage company profiles.
- **Job Postings**: Post job openings with details like title, description, requirements, and salary.
- **Application Management**: Review applications, filter candidates, and contact shortlisted applicants.

### Additional Features
- **Admin Panel**: Manage users, jobs, and site content.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile.
- **Notifications**: Email and in-app notifications for job updates and application status.

## Tech Stack

### Frontend
- **HTML5/CSS3**: Structure and styling.
- **JavaScript**: Interactive elements.

### Backend
- **Node.js**: Server-side runtime.
- **Express.js**: Backend framework for routing and APIs.
- **MongoDB** : Database for storing user profiles, job posts, and applications.

### Authentication
- **JWT** (JSON Web Tokens): For secure user sessions.
- **bcrypt**: For hashing passwords.
